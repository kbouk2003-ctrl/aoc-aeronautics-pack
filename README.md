# All of Create Aeronautics – Custom (packwiz)

Minecraft 1.21.1 · NeoForge 21.1.264 · packwiz pack. Clients and the server sync from this repo on launch.

- Pack URL for packwiz-installer: `https://raw.githubusercontent.com/kbouk2003-ctrl/aoc-aeronautics-pack/main/pack.toml`
- Client: Prism Launcher instance with pre-launch command
  `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/kbouk2003-ctrl/aoc-aeronautics-pack/main/pack.toml`
- Server: `java -jar packwiz-installer-bootstrap.jar -g -s server <pack URL>` runs before the server starts (see run.bat).

Mods are downloaded from Modrinth/CurseForge; only metadata and configs live here.
